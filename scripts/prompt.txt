You are given a Python function that is intended to perform a topological sort, but it silently produces incorrect output on graphs with multiple valid orderings or graphs that include nodes with zero in-degree discovered late. Analyze the code, identify the exact logical design flaw, propose a corrected algorithm, and then rewrite the entire function in clean Python 3.

Graph is represented as a dictionary mapping a node to a list of its outgoing neighbors.

Provide:
1. A short explanation of the bug in the original logic
2. A corrected version of Kahn’s algorithm that handles all valid DAGs
3. A complete rewritten Python function

Here is the buggy function:

def topo_sort(graph):
    indegree = {n: 0 for n in graph}
    for src in graph:
        for dst in graph[src]:
            indegree[dst] += 1

    queue = [n for n in indegree if indegree[n] == 0]
    result = []

    while queue:
        node = queue.pop()
        result.append(node)
        for nei in graph.get(node, []):
            indegree[nei] -= 1
            if indegree[nei] == 0:
                queue.append(nei)

    return result
